# 👁️ Computer Vision & Edge AI Portfolio

Цей репозиторій є портфоліо моїх навчальних та практичних проектів у сфері комп'ютерного зору (Computer Vision) та штучного інтелекту. 
Головний фокус — обробка відео в реальному часі, розпізнавання об'єктів та інтеграція AI-алгоритмів з апаратними платформами (Edge AI / IoT / Robotics).

## 🛠 Технічний стек
* **Нейромережі (Deep Learning):** YOLOv8 (Ultralytics), Custom Model Training (Transfer Learning), PyTorch (CUDA Hardware Acceleration).
* **High-Performance Inference:** C++ (OpenCV DNN, ONNX Runtime), OpenVINO (INT8 Quantization), TensorRT (FP16, Layer Fusion).
* **Трекінг та Алгоритми:** ByteTrack (SORT), Фільтр Калмана (Kalman Filter), Monocular Depth Estimation.
* **Обробка зображень та Відео:** C++ / Python (OpenCV), **GStreamer (Zero-latency hardware decoding)**, обробка MJPEG/MP4/UVC-потоків.
* **Архітектура та Оптимізація:** Multithreading (C++ `std::thread`, `mutex`), Memory/Tensor Integrity, Asynchronous Python, FastAPI.
* **Мережа та Інтеграція:** HTTP/REST, взаємодія з мікроконтролерами (ESP32/STM32) через локальну мережу, Hardware-in-the-Loop (HIL) тестування, PWM Servo Control.
* **Інструменти:** C/C++ Core, Linux (Ubuntu/Bash), CMake, VS Code, Git/GitHub.

## ⚡ Оптимізація продуктивності (Edge AI Optimization)

Одним із ключових завдань під час розробки було дослідження проблеми "вузького горлечка" (CPU bottleneck) при запуску важких нейромереж на Edge-пристроях без використання дискретних GPU.

### ⚙️ C++ Multithreaded Inference Engine
Для досягнення максимальної швидкодії на слабкому "залізі", логіка інференсу була повністю переписана з високорівневого Python на **C++**. 
* **ONNX Integration:** Модель YOLOv8 експортовано у формат `.onnx` та інтегровано через C++ API (OpenCV DNN).
* **Multithreading:** Щоб усунути "мікрофрізи" відео під час розрахунків нейромережі, архітектуру розділено на паралельні потоки (`std::thread`). Читання відео та малювання тактичного HUD відбувається в основному потоці без затримок, тоді як AI працює у фоновому потоці.
* **Memory Safety & Frame Skipping:** Реалізовано безпечний доступ до тензорів через `cv::transpose` (для усунення пошкодження пам'яті / wild pointers) та інтегровано розумний пропуск кадрів. 
* **Результат:** Запуск C++ рушія дозволив розвантажити CPU та підняти плавність роботи відео до стабільних 30 FPS, з паралельним фоновим інференсом на рівні ~12 FPS суто на потужностях мобільного процесора.

### 🧠 OpenVINO INT8 Quantization (Python)
У рамках R&D на Python, базову модель (`FP32`) було відкалібровано та жорстко квантизовано до формату `INT8` за допомогою фреймворку **OpenVINO**.

| Формат Моделі | Математика | Час обробки кадру (Latency) | Кадрів на секунду (FPS) | Навантаження на RAM |
| :--- | :--- | :--- | :--- | :--- |
| **PyTorch (.pt)** | `FP32` (Дроби) | ~350 мс | ~2.8 FPS | Високе (~1 ГБ, ризик OOM) |
| **OpenVINO** | `INT8` (Цілі) | **~155 - 200 мс** | **~5.0 - 6.4 FPS** | **Мінімальне** |

*(Примітка: конвертація в `INT8` усунула випадки примусового завершення процесу системою (OOM Killer) на Edge-пристроях з малим обсягом пам'яті).*

### 🚀 GPU-Оптимізація (NVIDIA TensorRT)
Для цільового апаратного забезпечення з дискретними GPU (архітектура Pascal), пайплайн інференсу переведено на високооптимізований рушій **NVIDIA TensorRT**.
Зниження точності ваг до FP16 (Half-precision), застосування **Layer Fusion** та фіксація графа обчислень (Memory Allocation Plan) дозволили стабілізувати FPS та усунути динамічний оверхед PyTorch.
